# Third-party sources and redistribution boundary

This repository publishes project code and aggregate experiment documentation. It does not include the course evaluation kit, public-test conversations, lecture slides, recordings, downloaded datasets, pretrained weights, trained adapter weights, or downloaded BFCL tool implementations.

## Models

- Qwen/Qwen3-0.6B-Base — training base.
- Qwen/Qwen3-0.6B — tokenizer and chat template.
- Qwen/Qwen3-8B — the course response judge.

Revisions are recorded in `records/model_revisions.json`. Obtain model files from their original publishers under the applicable upstream terms.

## Data and executable tools

The sources are ToolACE, Glaive function-calling v2, Hermes function-calling v1, and the Berkeley Function Calling Leaderboard. Full repository IDs and fixed revisions are recorded in `records/data_revisions.json` and linked in `docs/DATA.md`.

The original project source notes recorded Apache-2.0 for these dataset sources and the BFCL tool implementation. This statement describes those recorded sources; it does not relicense upstream data or substitute for their notices. Fetch scripts download originals into ignored local directories. Retain and consult upstream license/attribution files when obtaining them.

BFCL implementation source: `ShishirPatil/gorilla`, commit `6ea57973c7a6097fd7c5915698c54c17c5b1b6c8`, under its upstream Apache-2.0 terms. The third-party implementation itself is not vendored here.

The course-provided `hw3/` package is a separate prerequisite. Its evaluator is used without alteration; its source, benchmark inputs, and lecture materials are intentionally omitted. The negotiation interface extractor reads the authorized local course pack rather than shipping a copy of the benchmark.

## Software and development assistance

Training uses PyTorch, Hugging Face Transformers, PEFT and vLLM; dependency pins are in `code/env/requirements.lock.txt`. Each dependency retains its own license. Claude Code and OpenAI Codex assisted with code, synthetic policies and analysis; reported evaluation numbers are generated by the course metrics, not by an AI assistant's estimate.

No repository-wide license is being applied to upstream materials. Publishing this source is not a grant of rights to redistribute the excluded course materials, datasets or model artifacts.
