# 已核對的實驗結果

本文於 2026-11-17 根據現有官方 metrics 與最終提交 ZIP 重新整理。精確數值和原始 metrics 檔案的雜湊保存於 [results.json](results.json)，沒有重新訓練或生成 benchmark 預測。

## 指標

- **Part 1**：課程評分器的 weighted step accuracy，含 first-step 規則；must-call 的權重為 10，其餘為 1。完整公開資料 13,021 步。
- **訂單正確率**：模型實際下出的訂單中，商品、數量、最新報價及預算等規則皆合法的比例。
- **成交率**：2,607 場談判中至少有一筆有效訂單的比例。
- **相對成交價格**：第一筆有效訂單的單價除以 gold price，對有成交的談判平均；較低較好。1.0266 不是「省下 2.66%」。不同模型成交集合可能不同。
- **文字合理率**：由指定 Qwen3-8B judge 評判模型產生的文字，並非人工逐筆審查。無 judge 的實驗保留為未計算，不補造數字。

## 能推論與不能推論的事

- 微調後公開表現明顯優於 Base，但 Part 1 未達 70%。
- E27 的提高有相當部分來自官方接受的第一步文字確認；需另看 must-call，不能只把總分當一般工具執行能力。
- 新政策／流程在同源 dev 接近滿分，不能保證遷移到未見過的流程。
- E30 的兩種政策表達得到接近分數，只能說這兩次短程設定沒有明顯額外收益；不能據此證明流程種類一定比語言表達重要。
- 公開分數參與了最終版本取捨，不能稱為從未參與選模的完全盲測。
- 沒有把多個模型各自較好的指標拼接成一個結果，也沒有把離線替換預測的理論上限當實測成績。

## 更新數字

若仍保有原工作區，可執行 CPU-only 匯出器：

```bash
python code/audit/export_results.py \
  --root /path/to/original-workspace \
  --submission-zip /path/to/submission.zip \
  --out /path/to/new-results.json
```

它只讀既有完整 metrics、雜湊與 ZIP 內的 adapter，不開始訓練或評測，也不輸出題目、答案或權重。輸出檔須使用新路徑。
